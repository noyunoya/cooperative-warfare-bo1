# Cooperative Warfare - Black Ops 1 (Cuba-Co-Op)

Co-op for Black Ops 1 Operation 40 (cuba) under Plutonium: P1 Mason, P2 Woods, P3 Bowman, P4 Carlos. A joining player wears the body of their hero; during hero cutscenes the player's camera follows the hero.

**No game data or game scripts are in this repo** (the release mod.iwd also contains modified copies of the game's own scripts, so it is not published here).

- `mod/_cubacoop.gsc` - our co-op script. `mod/INSERTION_POINTS.md` - the two lines the game's scripts need to call it.
- `tools/` - install script, launcher .bat (`bo1_coop_launch.bat`), release README.
- `notes/` - project notes.
